# refynora-legal

Refynora’nın yasal ve destek sayfaları — GitHub Pages üzerinden yayında:
https://halilcosdu.github.io/refynora-legal/

**Kaynak metinler** ana depodaki `resources/views/legal/*.blade.php`
dosyalarıdır; buradaki sayfalar onlardan üretilmiştir. Yasal metin
değiştiğinde iki yer birlikte güncellenir. Tasarım belirteçleri
`DesignSystem/Tokens.swift` ile aynıdır (koyu öncelikli, mercan vurgu,
Poppins başlıklar).

Yollar App Store Connect’e kayıtlıdır, değiştirilmez:
`/gizlilik /kosullar /destek` (TR) · `/privacy /terms /support` (EN).
